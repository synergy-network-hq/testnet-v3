# Requirements audit

This audit maps all 43 sections of the benchmark brief to evidence in this package. `COMPLETE` means the requested work was performed and documented. `BOUNDED` means the request was handled to the safe and technically supportable boundary, with unavailable quantities explicitly classified `NOT_MEASURED`. `NOT APPLICABLE` means the frozen implementation lacks the required production path and no substitute was fabricated.

| Brief section | Status | Evidence and disposition |
|---:|---|---|
| 1. Primary objective | BOUNDED | Controlled primitive and local production-path costs are measured in `RESULTS.md` and `PAPER_TABLES.md`. Live/multi-node protocol costs remain explicit in `NOT_MEASURED.md`. |
| 2. Repository inspection | COMPLETE | `SOURCE_RECONNAISSANCE.md`, `algorithm-inventory.csv`, and `ALGORITHM_MATRIX.md` trace implementations, call paths, roles, feature flags, and reachable/dead boundaries. |
| 3. Freeze implementation | COMPLETE | `environment.json`, `ENVIRONMENT.md`, run manifests, and checksums bind source, branch, dirty state, toolchain, target, profile, dependencies, host, Genesis, and selected portable implementation. |
| 4. Protect running network | COMPLETE | Saturation remained local; the shared environment received only a passive, sanitized, one-session observation. No key material, endpoint, credential, configuration, or persistent state is retained or changed. |
| 5. Benchmark suite | COMPLETE | `src/main.rs`, `src/bin/cold_start.rs`, `run.sh`, `analyze.py`, and `report.py` implement distinct primitive, Aegis, lifecycle, protocol, negative, cold-start, load, and analysis suites. |
| 6. Primitive measurements | COMPLETE | All six runtime-exposed algorithms have applicable key/sign/verify/KEM and size results. Signature message sizes span 32 B through 16 KiB plus representative profiles; batch verification includes 10/100/1,000 and protocol-specific groups. Current votes are absent. |
| 7. Aegis overhead | COMPLETE | Direct primitive, PQCManager, and Aegis medians and explicit absolute/percentage differences are reported in Tables 2–3 and `RESULTS.md`, with semantic-path cautions. |
| 8. Key lifecycle | COMPLETE | Registration, lookup, role/active/revocation checks, revocation, rotation, and lifecycle root are measured. Root scaling covers registry populations 1, 10, 100, 1,000, and 10,000. |

| 10. Transaction bytes | COMPLETE | Actual unsigned, signed-public, typed-envelope, carrier, witness, and authentication-delta sizes across payload sizes appear in Table 4 and generated CSVs. |
| 11. Block bytes | BOUNDED | Exact current committed frames are measured at counts 1–1,000 with dense 8 MiB-boundary sampling and authentication deltas. No equivalent classical production mode exists, so none is invented. |
| 12. End-to-end transaction latency | BOUNDED | Local construction, signing, serialization, deserialization, validation, admission, envelope, and carrier stages are measured. RPC submission, inclusion, finality, and receipt timing are `NOT_MEASURED` because no active safe endpoint/topology was available. |
| 13. Throughput/load | BOUNDED | Three independent controlled unique-signature verification-pool runs measure accepted work, saturation, latency, CPU/wall, and RSS. No disposable node network existed, so network TPS and node telemetry remain `NOT_MEASURED`; verification/s is never relabeled TPS. |
| 14. Consensus authentication | BOUNDED | Current assignment, producer-block, coordinator-commit, exact frames, and package build/verify are measured. Source call counts and role behavior are audited. Vote/QC/VC/TC costs are not current-mode quantities. |
| 15. Validator scaling | BOUNDED | Counts 4, 6, 7, 10, 16, 25, and 50 are formula-derived from audited message flows and measured frames/Aegis costs. No row is labeled instantiated or live. |
| 16. Algorithm agility | COMPLETE | `ALGORITHM_MATRIX.md` documents identifier representation, role/domain selection, coexistence, registry bindings, rejection paths, and the boundary between measured policy checks and unproven downgrade resistance. |
| 17. Negative paths | BOUNDED | Corruption, wrong key/ID/domain/role/lifecycle state/algorithm, malformed data, changed transaction, and KEM ciphertext cases are retained. Modified-vote testing is not applicable to current mode. HQC panics are failures, not normalized rejections. |
| 18. Initialization/cold start | BOUNDED | Thirty fresh processes measure initialization and first/subsequent sign/verify work. Full node startup attribution remains `NOT_MEASURED` without a disposable faithful node. |

| 25. Raw data | COMPLETE | Authoritative timestamped per-operation CSVs under `results/runs/*/raw/` retain run/environment/commit/suite/layer/algorithm/operation/workload/iteration/wall/CPU/RSS/result/work/size/timing context. `results/raw/README.md` points to them without duplicating evidence. |

| 43. Research standard | COMPLETE | Source capability, current deployment, direct measurement, derivation, existing telemetry, and unknowns are mechanically and narratively separable throughout the package. |

## Audit conclusion

All requested sections are handled at their safe and evidentially valid boundary. The controlled single-host study is complete and presentable. The broader objective of characterizing live or isolated multi-node network behavior remains a documented future experiment rather than a hidden gap. No `NOT_MEASURED` item has been converted into an estimate, zero, or headline measurement.
