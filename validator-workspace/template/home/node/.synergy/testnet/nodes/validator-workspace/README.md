# Validator Workspace

Canonical operator-facing workspace for one Synergy Testnet validator.

Active services should use canonical absolute paths under `/etc/synergy/validator`, `/var/lib/synergy/validator`, `/var/log/synergy/validator`, and `/opt/synergy/bin`. This workspace may contain symlinks, operator notes, generated reports, and control-panel state, but it must not become a validator-specific one-off layout.
