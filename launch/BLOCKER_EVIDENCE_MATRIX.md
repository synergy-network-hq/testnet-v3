# Testnet-v3 P0/P1 blocker-to-evidence matrix

Audit date: 2026-07-25

Launch decision: **NOT READY**

The canonical machine-readable status mapping is
`launch/launch-control-status.json`.  It separates component implementation,
production-path integration, distributed qualification, operational evidence,
and the final gate for every control below.  This matrix remains the detailed
human evidence record.

This matrix uses only `PASS`, `FAIL`, `BLOCKED`, and `NOT_APPLICABLE`.
Passing an isolated implementation control does not close its parent launch
gate. Hashes are SHA-256 snapshots of the named evidence at the time recorded;
they must be regenerated in the final release manifest after the source tree is
frozen.

The separate identity workstream owns all wallet, validator, node, consensus,
ingress, and fee-collector identity generation and the node credentials
workbook. This workstream does not generate, replace, or record those
identities.
